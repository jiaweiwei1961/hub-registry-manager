# Hub Registry - 系统状态 (System Status) 设计

## 页面概述
全面的系统监控页面，展示所有服务健康状态、资源使用情况、实时告警和系统日志。

## 组件设计

### 1. 服务健康卡片

#### 结构
```
┌─────────────┐
│   [图标]    │
│             │
│   服务名    │
│    状态     │
│             │
│   响应时间  │
└─────────────┘
```

#### 样式
- **尺寸**: 100px × 120px
- **背景**: 玻璃态
- **边框**: 
  - 正常: 1px solid rgba(0, 212, 255, 0.3)
  - 警告: 1px solid rgba(255, 145, 0, 0.5)
  - 错误: 1px solid rgba(255, 23, 68, 0.5)
- **状态指示器**: 顶部彩色条 + 脉冲光点

#### 状态颜色
| 状态 | 颜色 | 脉冲效果 |
|-----|------|---------|
| 正常 | #00E676 | 缓慢脉冲 |
| 警告 | #FF9100 | 中等脉冲 |
| 错误 | #FF1744 | 快速闪烁 |
| 未知 | #8B9DC3 | 无 |

### 2. 资源使用指示器

#### 结构
```
标签
████████████████████░░░░  78%
数值详情
```

#### 样式
- **进度条高度**: 8px
- **圆角**: 4px
- **背景**: rgba(255,255,255,0.1)
- **填充**: 根据使用率变色
  - 0-60%: Tech Blue
  - 60-80%: 黄色
  - 80-100%: 红色
- **发光**: 高使用率时红色发光

### 3. 告警卡片

#### 结构
```
┌─────────────────────────────┐
│ ● 告警标题                   │
│   时间戳    │   [查看按钮]   │
└─────────────────────────────┘
```

#### 样式
- **背景**: 根据级别变色
  - 警告: rgba(255, 145, 0, 0.1)
  - 严重: rgba(255, 23, 68, 0.1)
- **边框**: 左侧 3px 彩色条
- **悬浮**: 高亮 + 阴影

### 4. 日志查看器

#### 样式
- **背景**: #0D1117
- **字体**: 等宽字体
- **行号**: 可选显示
- **时间戳**: 灰色
- **级别标签**: 彩色徽章
- **服务名**: Tech Blue

#### 级别颜色
| 级别 | 颜色 | 背景 |
|-----|------|------|
| DEBUG | #8B9DC3 | 透明 |
| INFO | #00D4FF | rgba(0,212,255,0.1) |
| WARN | #FF9100 | rgba(255,145,0,0.1) |
| ERROR | #FF1744 | rgba(255,23,68,0.1) |
| FATAL | #FFFFFF | rgba(255,23,68,0.3) |

## 交互设计

### 服务卡片交互
- **悬浮**: 放大 + 发光边框
- **点击**: 打开服务详情弹窗
- **健康检查**: 点击刷新按钮重新检查

### 资源监控
- **实时更新**: 每5秒自动刷新
- **趋势图**: 点击查看历史趋势 (24h/7d/30d)
- **阈值告警**: 超过阈值时视觉提示

### 告警管理
- **标记已处理**: 点击移出活动告警列表
- **忽略**: 不再显示此告警
- **批量操作**: 多选后批量处理

### 日志操作
- **过滤**: 按级别、服务、时间筛选
- **搜索**: 实时搜索日志内容
- **导出**: 下载为 .log 或 .json
- **实时**: 自动滚动最新日志

## 动画效果

### 状态脉冲
```css
@keyframes pulse {
  0%, 100% { opacity: 1; box-shadow: 0 0 5px currentColor; }
  50% { opacity: 0.6; box-shadow: 0 0 20px currentColor; }
}
```
- 正常: 3s infinite
- 警告: 2s infinite
- 错误: 1s infinite

### 进度条流动光效
```css
@keyframes shimmer {
  0% { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}
```
- 仅在高使用率时显示
- 营造紧迫感

### 数据刷新
- 数字变化: 滚动动画
- 卡片更新: 闪光效果
- 新告警: 滑入动画

## 响应式设计

### Desktop (>1024px)
- 6个服务卡片一排
- 资源监控和告警并排
- 完整表格显示

### Tablet (768-1024px)
- 3个服务卡片一排
- 资源监控和告警堆叠
- 表格横向滚动

### Mobile (<768px)
- 2个服务卡片一排
- 卡片式告警列表
- 简化服务表格
