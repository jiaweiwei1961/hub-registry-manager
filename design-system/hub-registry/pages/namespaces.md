# Hub Registry - 命名空间 (Namespaces) 设计

## 页面概述
管理镜像命名空间，支持公开/私有设置，展示统计信息。

## 组件设计

### 1. 页面头部
- **标题**: "命名空间" + 副标题 "管理镜像组织"
- **操作按钮**: 主按钮 "+ 创建命名空间"，科技蓝渐变
- **搜索区**: 搜索框 + 筛选下拉

### 2. 命名空间卡片

#### 卡片结构
```
┌────────────────────────────────────────────────────────────┐
│ [图标]  命名空间名称                    [状态标签] [操作]    │
│ ────────────────────────────────────────────────────────── │
│ 描述文字...                                                 │
│                                                            │
│ [仓库: N]  [镜像: N]  [下载: N]  [所有者: name]            │
└────────────────────────────────────────────────────────────┘
```

#### 样式细节
- **背景**: 玻璃态 rgba(26, 31, 46, 0.8)
- **边框**: 1px solid rgba(0, 212, 255, 0.15)
- **悬浮**: 边框发光 + 轻微抬升
- **图标**: 圆形渐变背景

#### 状态标签
| 类型 | 颜色 | 样式 |
|-----|------|------|
| 公开 | 绿色 | 绿色边框 + 绿色文字 |
| 私有 | 橙色 | 橙色边框 + 橙色文字 |

#### 统计信息
- 图标 + 数值格式
- 使用 Tech Blue 高亮数字

#### 样式
- **背景**: 深色半透明 + 模糊
- **边框**: 发光边框
- **入场**: 从中心缩放淡入

### 4. 操作菜单
- **触发**: 点击 ⋮ 图标
- **菜单项**: 编辑、删除、查看仓库
- **样式**: 深色下拉菜单，悬浮高亮

### 5. 分页器
- **样式**: 数字按钮 + 上一页/下一页
- **当前页**: 科技蓝背景
- **悬浮**: 边框发光

## 交互设计

### 卡片交互
- **悬浮**: 抬升 + 发光
- **点击**: 进入命名空间详情
- **操作菜单**: 点击展开

### 创建流程
1. 点击按钮 → 弹窗滑入
2. 填写表单 → 实时验证
3. 提交 → 按钮 Loading → 成功后卡片插入列表

### 删除确认
- 二次确认弹窗
- 输入命名空间名称确认
- 红色警告样式

## 响应式设计
- **Desktop**: 3列卡片网格
- **Tablet**: 2列卡片网格
- **Mobile**: 单列卡片，横向滚动统计
