## 组件设计

### 1. 系统健康状态面板
- **布局**: 2行3列网格
- **卡片样式**:
  - 玻璃态背景
  - 顶部彩色条（根据服务类型）
  - 左侧图标区域
  - 右侧：服务名 + 状态指示器
- **状态指示器**:
  - 健康: 绿色脉冲点 (#00E676)
  - 异常: 红色闪烁点 (#FF1744)
  - 动画: 2s infinite pulse

| 服务 | 图标 | 颜色条 |
|-----|------|-------|
| Gateway | 🌐 | 蓝色 |
| Web API | 🔌 | 青色 |
| Registry Core | 📦 | 紫色 |
| MinIO | ☁️ | 橙色 |
| PostgreSQL | 🐘 | 深蓝 |
| Redis | ⚡ | 红色 |

### 2. 数据统计卡片
- **布局**: 4列等宽
- **卡片结构**:
  ```
  ┌──────────────────┐
  │ [图标]           │
  │                  │
  │     数值         │  ← 大字号，霓虹发光
  │     标签         │  ← 小字号，灰色
  │ [趋势 ↑ 12%]    │  ← 可选
  └──────────────────┘
  ```
- **数值样式**: 32px, 700w, 渐变文字效果
- **图标**: 56px 圆形渐变背景

### 3. 系统信息面板
- **玻璃态卡片**
- **内容**:
  - 版本信息
  - 运行环境
  - API版本
  - Registry地址（可点击复制）
- **样式**: 标签-值 对齐布局

### 4. 镜像操作指南
- **分栏布局**: 上传 / 下载
- **步骤样式**:
  - 圆形编号（发光边框）
  - 标题 + 代码块
  - 复制按钮
- **代码块**: 深色背景，语法高亮

## 交互设计

### 悬浮效果
- 卡片: translateY(-4px) + 发光增强
- 按钮: 光晕扩散
- 链接: 颜色变亮

### 数据刷新
- 刷新按钮旋转动画
- 数据更新时数字滚动效果
- 最后更新时间显示

### 点击交互
- 健康卡片: 跳转详情
- 统计卡片: 跳转列表
- 代码块: 一键复制

## 入场动画
1. 页面背景淡入 (0-200ms)
2. 健康卡片依次从左到右滑入 (200-600ms)
3. 统计卡片从下方弹入 (400-800ms)
4. 底部面板淡入 (600-1000ms)
