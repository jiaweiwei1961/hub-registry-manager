# Hub Registry - 镜像复制 (Image Replication) 设计

## 页面概述
管理镜像复制策略，支持跨registry复制镜像，实时显示复制任务进度和状态。

## 组件设计

### 1. 策略卡片

#### 结构
```
┌─────────────────────────────────────────────────────────────┐
│ [图标] 策略名称                          [状态开关] [操作]    │
│ ─────────────────────────────────────────────────────────── │
│ 描述文字                                                     │
│                                                             │
│ 源: source.com/* → 目标: local/*                           │
│ 触发: 定时/手动/事件   │   上次执行: X天前                   │
│ ─────────────────────────────────────────────────────────── │
│ [仓库数] [成功数] [失败数] [待处理数]                       │
└─────────────────────────────────────────────────────────────┘
```

#### 样式
- **背景**: 玻璃态 rgba(26, 31, 46, 0.8)
- **边框**: 根据状态变色
  - 启用: Tech Blue 边框 + 脉冲光点
  - 禁用: 灰色边框
- **状态开关**: 滑动开关，绿色/灰色

### 2. 进度条

#### 样式
```
┌────────────────────────────────────────┐
│ ████████████░░░░░░░░  60% (6/10)      │
└────────────────────────────────────────┘
```
- **背景**: rgba(255,255,255,0.1)
- **填充**: 科技蓝渐变
- **发光**: 进度条末端微光效果
- **动画**: 流动光效 (running状态)

#### 状态颜色
| 状态 | 颜色 | 图标 |
|-----|------|------|
| 等待 | 灰色 | ○ |
| 运行中 | Tech Blue | ● (脉冲) |
| 成功 | 绿色 | ✓ |
| 失败 | 红色 | ✗ |
| 暂停 | 橙色 | ⏸ |

### 3. 执行历史表格

#### 表头样式
- 深色背景 (#1A1F2E)
- Tech Blue 文字
- 可点击排序

#### 行样式
- 交替背景色
- 悬浮高亮
- 状态列带颜色指示器

### 4. 日志查看器

#### 结构
```
┌────────────────────────────────────────┐
│ [过滤 ▼] [自动滚动 ▼] [清空] [下载]   │
│ ─────────────────────────────────────  │

│  [00:00:15] INFO  Starting...         │
│  [00:00:18] INFO  Pulling manifest    │

│  [00:00:25] ERROR Failed to copy      │
│                                        │
└────────────────────────────────────────┘
```

#### 样式
- **背景**: 深色 (#0D1117)
- **字体**: 等宽字体 (JetBrains Mono, Fira Code)
- **级别颜色**:
  - INFO: Tech Blue
  - WARN: 橙色
  - ERROR: 红色
  - DEBUG: 灰色
- **自动滚动**: 最新日志保持在底部

## 交互设计

### 策略卡片交互
- **悬浮**: 抬升 + 发光边框
- **点击**: 进入详情页
- **开关**: 即时切换启用/禁用状态
- **操作菜单**: 编辑、删除、立即执行

### 进度展示
- **实时更新**: WebSocket 或轮询更新进度
- **速度显示**: 实时计算下载/上传速度
- **剩余时间**: 根据速度估算剩余时间

### 任务控制
- **暂停**: 可暂停正在执行的任务
- **停止**: 立即停止并标记为失败
- **重试**: 失败任务可重试

### 创建流程
1. **步骤1**: 填写基础信息
2. **步骤2**: 配置源registry
3. **步骤3**: 配置目标registry
4. **步骤4**: 设置触发规则
5. **确认**: 预览规则，提交创建

## 动画效果

### 状态指示器
- **运行中**: 脉冲动画 (2s infinite)
- **等待**: 呼吸动画 (3s infinite)
- **完成**: 缩放弹出效果

### 进度更新
- **数字滚动**: 进度数字变化时滚动效果
- **进度条**: 平滑过渡 (300ms ease)

### 卡片入场
- 依次从左到右淡入
- 间隔: 100ms
- 时长: 400ms

## 颜色应用

### 状态颜色
| 类型 | 颜色 | 用途 |
|-----|------|------|
| 成功 | #00E676 | 成功状态、完成指示 |
| 失败 | #FF1744 | 错误、失败状态 |
| 警告 | #FF9100 | 警告、暂停状态 |
| 信息 | #00D4FF | 信息、运行中状态 |

### 进度条

- 填充: linear-gradient(90deg, #00D4FF, #00FFE0)
- 发光: box-shadow: 0 0 10px rgba(0, 212, 255, 0.5)
