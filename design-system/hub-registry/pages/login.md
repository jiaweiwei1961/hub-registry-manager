# Hub Registry - 登录页设计

## 页面概述
科技感登录界面，深色背景配合霓虹光效，营造未来感。

### 特效设计

#### 1. 背景效果
- **网格纹理**: 50px 间隔的淡蓝色网格线
- **粒子效果**: 缓慢移动的科技蓝粒子
- **中心光晕**: 从中心向外扩散的径向渐变
- **扫描线**: 从顶部到底部的细线扫描动画

#### 2. 登录卡片
- **玻璃态**: backdrop-filter: blur(20px)
- **发光边框**: 1px solid rgba(0, 212, 255, 0.3)
- **悬浮光晕**: box-shadow 多层发光效果
- **入场动画**: 从下方滑入 + 淡入

#### 3. Logo 设计
- **图标**: 六边形科技容器图标
- **发光效果**: text-shadow 多层光晕
- **动画**: 轻微脉冲呼吸效果

#### 4. 输入框
- **默认状态**: 半透明深色背景
- **聚焦状态**: 边框变为科技蓝发光
- **过渡动画**: 150ms ease 边框颜色过渡
- **图标**: 左侧用户/锁图标

#### 5. 登录按钮
- **默认**: 科技蓝渐变背景
- **悬浮**: 发光增强 + 轻微放大
- **点击**: 涟漪效果
- **禁用**: 灰色 + 禁用状态

### 响应式断点
- Mobile: < 768px - 卡片宽度 90%
- Tablet: 768px - 1024px - 卡片宽度 400px
- Desktop: > 1024px - 卡片宽度 420px

### 交互状态
| 状态 | 效果 |
|-----|------|
| 输入框聚焦 | 边框发光，图标变亮 |
| 按钮悬浮 | 光晕增强，scale(1.02) |
| 按钮点击 | 涟漪扩散 |
| 登录成功 | 整体淡出，跳转动画 |
| 登录失败 | 卡片轻微抖动 + 错误提示 |

### 入场动画序列
1. 背景淡入 (0-300ms)
2. Logo 从上方滑入 (200-500ms)
3. 卡片从下方滑入 (300-700ms)
4. 表单元素依次淡入 (500-900ms)

### 设计原则
- 深色背景减少眼睛疲劳
- 科技蓝传递专业/技术感
- 发光效果营造未来感
- 动画平滑提升质感
