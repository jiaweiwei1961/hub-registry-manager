# Hub Registry - 用户管理 (User Management) 设计

## 页面概述

## 组件设计

### 1. 用户列表项

#### 结构
```
┌─────────────────────────────────────────────────────────────────────┐
│ [选择框] │ [头像] │ 用户名 │ 邮箱 │ 角色 │ 状态 │ 操作 │
└─────────────────────────────────────────────────────────────────────┘
```

#### 样式
- **高度**: 64px
- **背景**: 交替色
- **悬浮**: 高亮 + 显示操作按钮
- **选中**: Tech Blue 边框

#### 头像样式
- 默认: 用户图标 + 渐变背景
- 尺寸: 40px
- 圆角: 50%

### 2. 角色徽章

#### 样式
| 角色 | 颜色 | 样式 |
|-----|------|------|
| 超级管理员 | 紫色 | 紫色背景 + 皇冠图标 |
| 开发者 | Tech Blue | 蓝色背景 + 代码图标 |
| 只读用户 | 绿色 | 绿色背景 + 眼睛图标 |
| 自定义 | 灰色 | 灰色背景 + 设置图标 |

### 3. 状态指示器

#### 样式
```
● 启用    ○ 禁用
```
- **启用**: 绿色圆点 + "启用" 文字
- **禁用**: 灰色圆点 + "禁用" 文字

### 4. 权限矩阵

#### 结构
```
┌─────────────────────────────────────┐
│ 权限项              │ [✓] [✗] [○] │
│                     │  是  否  继承 │
└─────────────────────────────────────┘
```

#### 样式
- **勾选**: 绿色背景
- **禁用**: 红色背景
- **继承**: 灰色背景

## 交互设计

### 用户列表交互
- **多选**: 复选框选择多个用户
- **全选**: 表头复选框
- **批量操作**: 选中后显示操作栏
- **排序**: 点击表头排序

### 用户详情交互
- **编辑**: 切换到编辑模式
- **禁用/启用**: 开关切换
- **重置密码**: 弹窗确认后生成新密码
- **删除**: 二次确认

### 角色管理
- **权限编辑**: 点击展开权限矩阵
- **继承**: 子角色继承父角色权限
- **冲突处理**: 显式权限覆盖继承权限

### 创建/编辑流程
1. **填写基本信息**: 用户名、邮箱等
2. **设置密码**: 手动或自动生成
3. **分配角色**: 选择角色模板
4. **确认**: 预览信息，提交

## 颜色系统

### 角色颜色
```css
--role-admin: #9C27B0;      /* 紫色 - 超级管理员 */
--role-developer: #00D4FF;  /* Tech Blue - 开发者 */
--role-readonly: #00E676;   /* 绿色 - 只读用户 */
--role-custom: #8B9DC3;     /* 灰色 - 自定义 */
```

### 状态颜色
```css
--user-active: #00E676;     /* 启用 */
--user-inactive: #8B9DC3;   /* 禁用 */
--user-locked: #FF1744;     /* 锁定 */
```

### 权限状态
```css
--perm-granted: #00E676;    /* 已授权 */
--perm-denied: #FF1744;     /* 拒绝 */
--perm-inherited: #8B9DC3;  /* 继承 */
```

## 动画效果

### 操作反馈
- **保存成功**: 绿色闪光 + 勾选动画
- **保存失败**: 红色抖动
- **删除确认**: 缩放弹出效果

### 列表更新
- **新增**: 从顶部滑入
- **删除**: 向左滑出
- **状态切换**: 颜色过渡

### 加载状态
- **表格**: 骨架屏
- **头像**: 脉冲占位
- **按钮**: Loading 旋转

## 响应式设计

### Desktop (>1024px)
- 完整表格布局
- 用户详情并排显示
- 完整权限矩阵

### Tablet (768-1024px)
- 简化表格
- 用户详情堆叠
- 权限分组折叠

### Mobile (<768px)

- 简化权限显示
