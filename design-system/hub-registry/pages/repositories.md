# Hub Registry - 镜像仓库 (Repositories) 设计

## 页面概述
管理镜像仓库，支持多视图切换，展示镜像列表和详情。

## 组件设计

### 1. 视图切换
- **卡片视图**: 网格布局，视觉优先
- **列表视图**: 表格布局，信息密度高
- **切换动画**: 淡入淡出 + 布局切换

### 2. 卡片视图

#### 卡片结构
```
┌─────────────────────┐
│                     │
│   [Docker 图标]     │
│                     │
│   repository-name   │
│   ─────────────     │
│   [公开] latest     │
│                     │
│   12 镜像 · 1.2K ↓ │
│                     │
└─────────────────────┘
```

#### 样式
- **尺寸**: 固定宽高比 4:3
- **背景**: 渐变深色 + 玻璃态
- **边框**: 根据状态变色
  - 公开: 蓝色边框
  - 私有: 橙色边框
- **图标**: 居中，80px，发光效果

#### 悬浮效果
- 卡片放大: scale(1.03)
- 发光增强
- 显示快捷操作按钮

## 交互设计

### 卡片交互
- **悬浮**: 抬升 + 发光 + 显示快捷操作
- **点击**: 进入详情页
- **右键**: 上下文菜单

### 表格交互
- **行悬浮**: 高亮 + 显示操作
- **排序**: 点击表头排序，显示箭头
- **多选**: 复选框选择多行

### 详情页交互
- **标签切换**: 镜像标签 / 复制策略 / 审计日志
- **复制命令**: 点击复制到剪贴板
- **删除**: 二次确认弹窗

### 视图切换动画
- **卡片→列表**: 卡片收缩淡出，列表展开淡入
- **列表→卡片**: 列表收缩淡出，卡片展开淡入
- 时长: 300ms

## 颜色应用
- **公开**: Tech Blue 边框 + 标签
- **私有**: Orange 边框 + 标签
- **悬停**: 边框发光增强
- **选中**: Tech Blue 背景高亮
