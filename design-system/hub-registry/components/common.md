# Hub Registry - 通用组件与交互设计

## 全局组件

### 1. 顶部导航栏
```
┌─────────────────────────────────────────────────────────────────────────┐
│  ◆ Hub Registry    │  搜索...           │ 🔔 │ 👤 admin [▼] │ 退出  │
└─────────────────────────────────────────────────────────────────────────┘
```

#### 结构
- **左侧**: Logo + 系统名称
- **中间**: 全局搜索框
- **右侧**: 通知图标、用户头像下拉、退出按钮

#### 样式
- **高度**: 60px
- **背景**: rgba(10, 14, 26, 0.95) + backdrop-blur
- **边框**: 底部 1px solid rgba(0, 212, 255, 0.1)
- **Logo**: Tech Blue 发光效果

#### 搜索框
```

```
- **宽度**: 400px
- **背景**: rgba(255,255,255,0.05)
- **聚焦**: 边框发光 + 展开下拉建议

## 反馈组件

### 1. Toast 通知
```
┌─────────────────────────────┐
│ ✓ 操作成功              [×] │
└─────────────────────────────────────── (右上角滑入)
```

#### 类型
| 类型 | 图标 | 颜色 |
|-----|------|------|
| 成功 | ✓ | 绿色 |
| 错误 | ✗ | 红色 |
| 警告 | ⚠ | 橙色 |
| 信息 | ℹ | Tech Blue |

#### 行为
- **位置**: 右上角
- **动画**: 从右滑入
- **自动消失**: 3秒后淡出
- **最大数量**: 3个

### 2. 工具提示

- **边框**: 1px solid rgba(0,212,255,0.3)
- **箭头**: 小三角指向触发元素

## 动画规范

### 1. 入场动画
```css
@keyframes fadeSlideIn {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
/* duration: 400ms, easing: ease-out */
```

### 2. 悬浮动画
```css
@keyframes float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-4px); }
}
/* duration: 2s, infinite */
```

### 3. 脉冲动画
```css
@keyframes pulse {
  0%, 100% { 
    opacity: 1;
    box-shadow: 0 0 5px var(--color);
  }
  50% { 
    opacity: 0.6;
    box-shadow: 0 0 20px var(--color);
  }
}
/* duration: 2s, infinite */
```

### 4. 旋转动画
```css
@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
/* duration: 1s, linear, infinite */
```

### 5. 发光动画
```css
@keyframes glow {
  0%, 100% {
    box-shadow: 0 0 5px var(--tech-blue),
                0 0 10px var(--tech-blue),
                0 0 20px var(--tech-blue);
  }
  50% {
    box-shadow: 0 0 10px var(--tech-blue),
                0 0 20px var(--tech-blue),
                0 0 40px var(--neon-cyan);
  }
}
/* duration: 3s, infinite */
```
