# 省级智能心理量表普测系统需求文档 (PRD)

> 创建日期: 2026-04-27
> 版本: v1.0

---

## 一、系统概述

### 1.1 系统定位

省级智能心理量表普测平台，面向全省200万中小学生，提供可配置量表库、在线答题、筛查预警、多维度报告分析功能。采用五级组织架构（省-市-区县-学校-班级），支持分散时段答题，日活5万，峰值3万并发。

### 1.2 主要用户角色

| 角色 | 职责范围 | 核心功能 |
|------|----------|----------|
| 省级管理员 | 全省数据 | 量表库管理、全省数据查看、省级报告 |
| 市/区县管理员 | 辖区数据 | 测评任务发布、数据查看、辖区报告 |
| 学校管理员 | 本校数据 | 测评组织、学生管理、学校报告 |
| 班主任 | 本班数据 | 答题监控、预警查看、班级报告 |
| 学生 | 个人数据 | 在线答题、查看个人报告 |

## 三、功能模块详细设计

### 3.1 量表管理模块

#### 3.1.1 功能概述

量表管理模块是系统的核心基础模块，提供心理量表的创建、配置、管理和版本控制能力。省级管理员负责维护量表库，市/区县管理员可选择使用已发布的量表。

#### 3.1.2 功能清单

| 功能点 | 功能描述 | 权限角色 |
|--------|----------|----------|
| 量表库列表 | 查看所有已创建量表，支持按类型、状态、创建时间筛选 | 省级/市级/区县级 |
| 量表创建 | 创建新的量表，填写基础信息、配置题目、设置计分规则 | 省级管理员 |
| 量表编辑 | 编辑量表内容，未发布量表可完全编辑，已发布量表需创建新版本 | 省级管理员 |
| 量表发布 | 将量表状态改为已发布，发布后下级单位可见并可选用于测评 | 省级管理员 |
| 量表下架 | 将量表状态改为已下架，下架后不再允许新建测评任务 | 省级管理员 |
| 量表预览 | 预览量表的答题效果，检查题目展示和逻辑跳转 | 省级管理员 |
| 量表版本管理 | 管理量表的历史版本，支持版本对比、回滚到历史版本 | 省级管理员 |
| 量表复制 | 复制现有量表作为新量表的基础，加速新量表创建 | 省级管理员 |
| 量表导入导出 | 支持JSON格式导入导出量表配置，便于跨环境迁移 | 省级管理员 |
| 量表分类管理 | 管理量表分类（如情绪类、人格类、学业类等） | 省级管理员 |

#### 3.1.3 量表基础信息

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 量表ID | String | 是 | 系统自动生成唯一标识 |
| 量表名称 | String | 是 | 量表的中文名称，如"中学生心理健康量表" |
| 量表英文名称 | String | 否 | 量表的英文名称 |
| 量表编码 | String | 是 | 量表的编码，用于系统内部标识，如"MHT" |
| 量表分类 | Enum | 是 | 选择所属分类 |
| 适用学段 | Enum | 是 | 小学/初中/高中/中职 |
| 适用年级 | Array | 是 | 可多选，如[1,2,3]表示一年级至三年级 |
| 量表简介 | Text | 是 | 量表的简要说明 |
| 量表说明 | RichText | 否 | 详细的量表说明，答题前展示给学生 |
| 题目数量 | Integer | 系统自动计算 | 量表包含的题目总数 |
| 预计用时 | Integer | 是 | 预估答题时长（分钟） |
| 计分方式 | Enum | 是 | 原始分/标准分/T分/百分位等 |
| 状态 | Enum | 是 | 草稿/已发布/已下架 |
| 创建人 | String | 系统自动 | 创建量表的管理员 |
| 创建时间 | DateTime | 系统自动 | 量表创建时间 |
| 版本号 | String | 系统自动 | 量表版本，如v1.0.0 |

#### 3.1.4 题目类型支持

| 题目类型 | 说明 | 示例 |
|----------|------|------|
| 单选题 | 从多个选项中选择一项 | "你经常感到焦虑吗？A从不 B偶尔 C经常 D总是" |
| 多选题 | 从多个选项中选择多项 | "你有哪些兴趣爱好？（可多选）A阅读 B运动 C音乐..." |
| 量表题 | 李克特量表，选项有顺序含义 | "1-5分评分，1=非常不同意，5=非常同意" |
| 填空题 | 文本输入答案 | "请描述你最近一周的心情：______" |
| 排序题 | 对选项进行排序 | "请将以下因素按重要程度排序：..." |
| 矩阵题 | 多行多列的批量选择题 | 多道题目共用同一组选项，以矩阵形式展示 |
| 日期题 | 选择日期 | "你的生日是？" |
| 数值题 | 输入数值 | "你的身高是（厘米）：____" |

#### 3.1.5 题目配置详情

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 题号 | Integer | 是 | 题目在量表中的序号，从1开始 |
| 题目内容 | RichText | 是 | 题目文本，支持富文本格式 |
| 题目类型 | Enum | 是 | 单选/多选/量表题/填空/排序/矩阵/日期/数值 |
| 选项配置 | JSON | 条件必填 | 单选/多选/量表题需要配置选项 |
| 分值配置 | JSON | 是 | 各选项对应的分值 |
| 所属维度 | Array | 是 | 题目所属的维度（可多个） |
| 是否必填 | Boolean | 是 | 该题是否必须回答 |
| 逻辑跳转 | JSON | 否 | 根据答案跳转到指定题目 |
| 题目提示 | String | 否 | 答题时显示的提示信息 |

#### 3.1.6 量表维度配置

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 维度ID | String | 系统自动生成 | 维度唯一标识 |
| 维度名称 | String | 是 | 维度中文名称，如"焦虑倾向" |
| 维度编码 | String | 是 | 维度编码，用于系统标识 |
| 维度说明 | Text | 否 | 维度的详细说明 |
| 计分题目 | Array | 是 | 属于该维度的题目ID列表 |
| 计分方式 | Enum | 是 | 累加/平均/加权等 |
| 得分范围 | JSON | 否 | 维度得分的最小值和最大值 |
| 等级划分 | JSON | 是 | 得分等级划分规则 |

**等级划分示例：**
```json
{
  "levels": [
    {"name": "正常", "min": 0, "max": 30, "color": "green"},
    {"name": "轻度异常", "min": 31, "max": 40, "color": "yellow"},
    {"name": "中度异常", "min": 41, "max": 50, "color": "orange"},
    {"name": "重度异常", "min": 51, "max": 100, "color": "red", "isWarning": true}
  ]
}
```

#### 3.1.7 逻辑跳转配置

支持根据题目答案跳转到指定题目，实现条件分支答题路径。

| 跳转类型 | 说明 | 示例 |
|----------|------|------|
| 无条件跳转 | 答完本题后固定跳转到下一题 | 顺序答题 |
| 条件跳转 | 根据答案跳转到不同题目 | "如果选A则跳转到第5题，否则继续" |
| 跳过区间 | 跳过一段题目 | "答完本题后直接跳转到第10题" |
| 提前结束 | 满足条件时提前结束测评 | "如果选A则结束测评" |

### 3.2 组织架构与用户管理模块

#### 3.2.1 功能概述

组织架构与用户管理模块维护全省的五级组织架构体系（省-市-区县-学校-班级），管理各级管理员、教师和学生用户，实现精细化的权限控制。

| 功能点 | 功能描述 | 权限角色 |
|--------|----------|----------|
| 组织架构树 | 可视化展示五级组织架构树，支持展开/收起 | 所有管理员 |
| 省级管理 | 管理省级管理员账号 | 省级管理员 |
| 市级管理 | 创建、编辑、禁用市级管理员账号 | 省级管理员 |
| 区县级管理 | 创建、编辑、禁用区县级管理员账号 | 市级管理员 |
| 学校管理 | 创建、编辑、禁用学校 | 区县级管理员 |
| 学校管理员管理 | 创建、编辑学校管理员账号 | 区县级管理员 |
| 班级管理 | 创建、编辑、合并、删除班级 | 学校管理员 |
| 班主任管理 | 分配班主任到班级，管理班主任权限 | 学校管理员 |
| 学生管理 | 学生信息的增删改查、批量导入导出 | 学校管理员/班主任 |
| 学生转学 | 处理学生跨学校/跨班级转学 | 学校管理员 |
| 学生毕业 | 批量处理学生毕业、数据归档 | 学校管理员 |
| 用户权限管理 | 分配角色和权限，管理数据可见范围 | 各级管理员 |
| 操作日志查询 | 查询用户操作日志 | 各级管理员 |

| 启用状态 | Boolean | 是 | 规则是否启用 |
